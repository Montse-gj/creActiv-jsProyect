MEMORIA — creActive

1. Introducción

creActive es una aplicación web que permite explorar, visualizar y reservar talleres creativos como dibujo, cerámica, música o textil.

El objetivo del proyecto es simular una plataforma de gestión de talleres donde el usuario puede descubrir actividades, guardarlas como favoritas y realizar una reserva para ver su detalle.

2. Objetivo del proyecto

El proyecto se ha desarrollado como ejercicio práctico para trabajar:

  • Consumo de API externa

  • Manipulación del DOM

  • Programación orientada a objetos

  • Gestión de eventos

  • Persistencia de datos en localStorage

  • Arquitectura modular en JavaScript

3. Funcionamiento general

La aplicación funciona en tres fases:

1. Obtención de datos

  • Se realiza una petición a una API de imágenes

  • Se usa un término base relacionado con “manualidades”

  • Se obtiene información visual de los talleres

2. Generación de talleres

  • Se crean objetos mediante la clase Workshop

  • Se complementan con datos locales almacenados en workshopExtended

  • Se asignan datos adicionales mediante matchExtended

3. Interacción del usuario

El usuario puede:

  • Ver talleres en la página principal

  • Buscar talleres por ciudad

  • Marcar favoritos

  • Reservar talleres para ver detalle de cada taller con galería

4. Arquitectura del proyecto

El proyecto está organizado en módulos:

  • APIManager.js → gestión de llamadas a la API

  • DOMManager.js → renderizado en pantalla

  • Listeners.js → eventos de usuario

  • StorageManager.js → gestión de localStorage

  • Workshop.js → creación y estructura de talleres

  • workshopExtended.js → datos adicionales

  • matchExtended.js → asignación aleatoria de datos

Separación en carpetas:

  • css/ estilos

  • js/ lógica

  • img/ui/ recursos visuales

5. Flujo de la aplicación

  1. El usuario accede a la página principal (index.html)

  2. Se cargan talleres generados desde API + datos locales

  3. Se pintan en el DOM mediante DOMManager

  4. El usuario interactúa:

    • Favoritos → guardados en localStorage

    • Reserva → guarda taller seleccionado y redirige a detalle

    • Búsqueda → filtra y vuelve a generar resultados

  5. En taller.html se muestra información ampliada y galería

6. Tecnologías utilizadas

  • HTML5

  • CSS3

  • JavaScript (ES6)

  • API externa (fetch)

  • localStorage

  • Programación orientada a objetos

7. Dificultades encontradas

Durante el desarrollo se han encontrado dificultades en:

  • Integración de datos provenientes de la API con datos locales

  • Organización del código en múltiples módulos

  • Gestión del flujo de información entre archivos

  • Coordinación entre eventos y renderizado del DOM
